# @conasa/n8n-nodes-exemplo

Pacote piloto da central de Community Nodes n8n da CONASA. Serve para validar o fluxo completo
(desenvolvimento → GitHub Actions → npm com provenance → instalação no n8n). **Não use em produção.**

## Instalação

n8n self-hosted: *Settings* → *Community Nodes* → *Install* → `@conasa/n8n-nodes-exemplo`.
Veja o [guia oficial de instalação](https://docs.n8n.io/integrations/community-nodes/installation/).

## Operações

**Example** — adiciona o campo `myString` (valor do parâmetro *My String*) a cada item de entrada.
